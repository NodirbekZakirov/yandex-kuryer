# Kuryer — лендинг и Telegram-бот

## Сайт (`site/`)

Статический, без сборки: `index.html` + `assets/`.

- Предпросмотр: `node serve.js` → http://localhost:4173
- Публикация: перетащите папку `site` на https://app.netlify.com/drop (или любой статический хостинг).
- Язык: узбекский по умолчанию, русский — по кнопке, по языку браузера или по ссылке `?lang=ru`.
- Узбекские тексты лежат прямо в разметке, русские — в объекте `RU` внизу `index.html`.
- Кнопки ведут в бот со ссылкой `?start=uz` / `?start=ru`, поэтому бот сразу открывается на нужном языке.

## Бот (`bot/`)

Нужен только Node.js 20.12+, зависимостей нет.

```
node bot/bot.js
```

- Настройки — в `bot/.env` (`BOT_TOKEN`, `ADMIN_IDS` через запятую).
- Тексты и ссылка на регистрацию — в `bot/texts.js`.
- Пользователи и статусы сохраняются в `bot/data.json`.

Как работает:

1. `/start` → выбор языка → информация + кнопки.
2. «Стать курьером» → инструкция и кнопка с регистрационной ссылкой.
3. Кандидат присылает скриншот → бот пересылает его админам с именем, @username и ID.
4. Админ жмёт «Подтвердить» или «Запросить заново» — кандидат получает уведомление.
5. Любой текст кандидата уходит админам; ответ (reply) на это сообщение бот пересылает кандидату.
6. `/stats` (только админы) — сколько людей пришло и прислало скриншот.

Важно: каждый админ должен один раз нажать `/start` в боте, иначе Telegram не даст боту ему писать.

Бот должен работать постоянно — для этого его нужно запустить на сервере (VPS, Railway, Render и т. п.)
с переменными `BOT_TOKEN` и `ADMIN_IDS`. Одновременно может работать только одна копия.
